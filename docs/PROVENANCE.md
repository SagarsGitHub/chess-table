# Source and license provenance

The Git history of this repository starts at [`SagarsGitHub/chess_automated` commit `163ae926c61ac2b9441b0d3503f875f1606709ee`](https://github.com/SagarsGitHub/chess_automated/commit/163ae926c61ac2b9441b0d3503f875f1606709ee). That project derives from WouterSchols' SmartChessboard framework. Its Python sources, original Sphinx `.rst` documentation and images, tests, README, setup file, and `LICENSE` are retained under `legacy/chess_automated/`. The generated Sphinx `_build` tree and its redirect page were removed; they can be rebuilt from those sources. The MIT license there retains `Copyright (c) 2021 WouterSchols`. The original documentation describes features that the checked-in hardware implementation does not currently provide; treat it as historical reference.

`firmware/` was copied from the workspace's newest available snapshot, `tmp/firmware-before-limit-diagnostics`, at repository creation on 2026-10-04. The snapshot is a PlatformIO Arduino Uno project and predates subsequent limit-diagnostic work indicated by its folder name. The user selected it as the starting firmware source. The import commit preserves that version and its knight/adjacent-parking limitations in Git history. The current `firmware/README.md` describes the later framed routing implementation. The reported magnet-release reset remains an unresolved hardware observation; diagnosis is deferred. The scratch `tmp/` directory is excluded from Git.

New computer-side integration code is separate from the legacy Python application. No remote Git history was available for the firmware snapshot. The legacy client and imported firmware were not compatible as imported. The current integrated host and Uno have since completed a 126-ply physical GUI game and a recovered reset; see the [roadmap](ROADMAP.md) for accepted milestones and remaining physical checks.
